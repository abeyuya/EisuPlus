EisuPlus

⌘キーで英数・かなを切り替え、修飾キーとマウスだけでウィンドウを動かす。メニューバーに常駐する小さな macOS アプリです。

できること

左 ⌘ 英数 右 ⌘ かな

⌘の単押しで英数・かな

US 配列のキーボードでも、JIS の英数キー・かなキーと同じ感覚で入力を切り替えられます。ショートカットで⌘を使ったときや長押ししたときは切り替わりません。

⌃ + マウス移動

ウィンドウを移動

キーを押したままマウスを動かすと、カーソルの下のウィンドウがクリックなしでついてきます。タイトルバーを探す必要はありません。

⌥ + マウス移動

ウィンドウをリサイズ

キーを押したままマウスを動かすと、ウィンドウの右下の角が動いてサイズが変わります。

左右の端 → 半分 ・ 上端 → 最大化

画面の端にスナップ

移動中にカーソルを画面の左右の端へ運ぶと画面の半分に、上端へ運ぶと最大化します。プレビューを見てからキーを離して確定します。

端に押し付けて待つ

隣のデスクトップへ運ぶ

移動中に左右の端へ押し付けたまま少し待つと、ウィンドウを隣のデスクトップへ運びます。

fn ⌃ ⌥ ⇧ ⌘

キーの組み合わせは自由

修飾キーと操作（マウス移動・左ドラッグ・右ドラッグ）の組み合わせを変えられます。移動やリサイズをしないアプリも指定できます。

インストール

  1. ダウンロードした zip を開き、EisuPlus.app を「アプリケーション」フォルダへ移動します。
  2. EisuPlus を開くと、メニューバーにアイコンが表示され、アクセシビリティの許可を求められます。
  3. 「システム設定」›「プライバシーとセキュリティ」›「アクセシビリティ」で EisuPlus をオンにします。
  4. 新しいバージョンが出ると、アプリが自動でお知らせします。メニューの「アップデートを確認…」からも確認できます。

アクセシビリティの許可が必要な理由

⌘キーの単押しを見分けて英数・かなキーを送ることと、ほかのアプリのウィンドウを移動・リサイズすることに使います。

キー入力は⌘の単押しかどうかを判定するためにその場で見るだけで、記録や送信はしません。EisuPlus はデータを一切収集しません。
