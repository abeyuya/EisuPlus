プライバシーポリシー

最終更新日: 2026年10月2日

EisuPlus（以下「本アプリ」）は、利用者の個人情報やデータを収集・保存・送信しません。

キー入力とマウス操作

本アプリは、⌘キーの単押しの判定と、修飾キーとマウスによるウィンドウ操作のために、キー入力とマウス操作をその場で参照します。参照した内容は記録せず、端末の外へ送信することもありません。

保存するデータ

キーの組み合わせや除外するアプリなどの設定は、お使いの Mac の中にだけ保存します。

通信

新しいバージョンがあるかを確認するため、本アプリは定期的にこのサイトの更新情報（appcast.xml）を取得し、アップデートをダウンロードするときは GitHub に接続します。このとき、本アプリから利用者を特定できる情報を送ることはありません。ただし、通信先（このサイトを置いている GitHub Pages と、アップデートを配布している GitHub）は、一般的な Web サーバーと同じく IP アドレスなどを記録することがあります。自動での確認は、本アプリの設定でオフにできます。

お問い合わせ

このポリシーについてのご質問は、GitHub の Issues へお寄せください。
